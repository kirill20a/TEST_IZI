# TEST IZI

Помощник для прохождения **своих тренировочных тестов** с помощью ИИ-чата
(по умолчанию DeepSeek). Программа делает скриншот вопроса, отправляет его в
чат, читает ответ и сама отмечает варианты на экране.

> ⚠️ Проект сделан для тренировки и развлечения на тестах, которые вы
> создали сами (пример лежит в `examples/it_test.html`). Не используйте его
> на настоящих зачётах, экзаменах и аттестациях: это списывание.

## Возможности

- **Четыре типа заданий:**
  - выбор одного или нескольких вариантов (кружки и квадратики);
  - ввод ответа текстом;
  - соответствие через выпадающие списки;
  - расстановка блоков по порядку перетаскиванием.
- **Два режима работы с ИИ:**
  - **«В фоне за тестом»** — чат открыт в отдельном окне браузера под тестом,
    программа работает с ним напрямую, без мыши и буфера обмена;
  - **«Рядом с тестом»** — экран делится пополам: слева тест, справа чат.
- **Автопилот** — решает тест до конца и сам нажимает «Следующий вопрос».
- **Безопасные остановки** — если ИИ не уверен в ответе (меньше 75%) или
  задание не распознано, программа ничего не нажимает и отдаёт вопрос вам.
- **Окно-приложение** с настройками и журналом, сборка в один `.exe`.
- **Портативный режим для флешки** — программа закрывается, когда флешку вынимают.

## Как это работает

1. Программа снимает экран и ищет на снимке элементы задания: кружки и
   квадратики, поле ввода, выпадающие списки или блоки с ручками «↕».
2. Отправляет снимок в ИИ-чат с номером вопроса. В начале чата один раз
   уходит инструкция: отвечать строкой вида `ОТВЕТ 302: 1, 3`.
3. Читает ответ со страницы чата и проверяет, что он подходит к заданию.
4. Отмечает варианты, вводит текст, выбирает пункты в списках или
   перетаскивает блоки, а затем нажимает «Следующий вопрос».

## Установка

Нужны Windows 10/11 и [Python 3.10+](https://www.python.org/downloads/)
(при установке отметьте «Add Python to PATH»).

```bat
git clone https://github.com/<ваш-ник>/TEST_IZI.git
cd TEST_IZI
pip install -r requirements.txt
python test_izi_app.py
```

## Использование

### Режим «В фоне за тестом» (рекомендуется)

1. В блоке «Чат с ИИ» выберите **«В фоне за тестом»**.
2. Нажмите **«Открыть браузер для ИИ»** — откроется отдельное окно Chrome или
   Edge со своим профилем. Один раз войдите в нём в DeepSeek.
3. Откройте тест и разверните его на весь экран поверх окна с чатом.
   Окно с чатом не сворачивайте.
4. Нажмите **F8** (один вопрос) или **F10** (автопилот).

Другой чат можно указать в поле «Адрес чата». Поле ввода и загрузку файла
программа ищет сама; если на каком-то сайте не найдёт, их можно задать
CSS-селекторами в «Тонкой настройке».

### Режим «Рядом с тестом»

1. Разделите экран: тест слева (Win+←), чат справа (Win+→).
2. В блоке «Чат с ИИ» задайте **поле ввода** и **кнопку «Копировать»**
   под ответом ИИ: нажмите «Задать» и за 3 секунды наведите мышь на нужное место.
3. Нажмите **F8** или **F10**.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| F6 | Запомнить кнопку «Копировать» (режим «Рядом с тестом») |
| F7 | Запомнить поле ввода чата (режим «Рядом с тестом») |
| F8 | Решить один вопрос |
| F9 | Включить или выключить нажатие «Следующий вопрос» |
| F10 | Запустить или остановить автопилот |
| F12 | Выход |

Аварийная остановка: резко увести мышь в любой угол экрана.

## Сборка в .exe

```bat
build.bat
```

Готовая программа появится в `dist\TEST_IZI.exe` и запускается без Python.
Перед повторной сборкой закройте запущенную `TEST_IZI.exe`.

## Версия для флешки

1. Скопируйте папку проекта на флешку.
2. Один раз запустите `build_flash.bat` — `TEST_IZI.exe` соберётся прямо на флешке.
3. На любом компьютере запускайте программу через `start.bat`.

`start.bat` создаёт файл-метку `flash_mode`: с ней программа закрывается через
1–2 секунды после извлечения флешки. Автоматического запуска при подключении
флешки нет: Windows отключила автозапуск с USB-накопителей в целях безопасности.

## Настройки

Все параметры хранятся в `split_config.json` рядом с программой и меняются из окна
приложения. Основные:

| Параметр | Что значит |
|---|---|
| `chat_mode` | `browser` — ИИ в фоне, `screen` — ИИ рядом с тестом |
| `chat_url` | Адрес ИИ-чата |
| `test_side` | Где тест в режиме «Рядом»: `left`, `right` или `full` |
| `read_mode` | Как читать ответ в режиме «Рядом»: `copy_button` или `page` |
| `upload_wait`, `first_check`, `answer_timeout` | Задержки отправки и ожидания ответа, в секундах |
| `dropdown_wait`, `drag_duration` | Задержки для списков и перетаскивания |

После каждого вопроса программа сохраняет `screenshots/last.png` с отмеченными
найденными элементами — по нему удобно проверять, что она видит.

## Структура проекта

```
test_izi_app.py     окно-приложение (интерфейс, настройки, журнал)
split_helper.py     логика: поиск элементов, ответы ИИ, клики и перетаскивание
browser_chat.py     работа с ИИ-чатом в фоновом окне браузера
build.bat           сборка dist\TEST_IZI.exe
build_flash.bat     сборка TEST_IZI.exe прямо в папку (для флешки)
start.bat           запуск с флешки
examples/it_test.html  тренировочный тест на 15 вопросов всех типов
```

## Ограничения

- Работает только в Windows.
- Качество ответов зависит от ИИ: на тренировочном тесте DeepSeek набрал
  83% (10 из 12), ошибаясь на вопросах с подвохом.
- Если сайт ИИ-чата изменит устройство страницы, режим «В фоне» может
  потребовать правки настроек.
- Пока открыто окно браузера для ИИ, у него включён отладочный порт.
  Закрывайте это окно после работы и не входите в нём в почту или банк.
